# Instagrab Setup Guide للـ GitHub Pages

## 🎯 المشروع الجديد: Instagrab

### 📁 الملفات المطلوبة للرفع:

```
instagrab-repo/
├── index.html (الـ landing page الجديدة)
├── Instagrab.exe (الملف التنفيذي)
└── README.md (اختياري)
```

## 🚀 خطوات الرفع على GitHub:

### 1. إنشاء Repository جديد:
```
Repository Name: instagrab
Description: 🎯 Grab rare Instagram usernames instantly - The fastest username generator
```

### 2. رفع الملفات:
```bash
# Initialize git
git init

# Add files
git add index.html
git add Instagrab.exe
git add README.md  # if you have one

# Commit with new branding
git commit -m "🎯 Launch Instagrab - Rare Instagram Username Grabber"

# Connect to GitHub
git remote add origin https://github.com/YOUR_USERNAME/instagrab.git
git branch -M main
git push -u origin main
```

### 3. تفعيل GitHub Pages:
1. اذهب لـ **Settings** في الـ repo
2. اختر **Pages** من الشمال
3. اختر **Deploy from a branch**
4. اختر **main branch / root**
5. احفظ

### 4. النتيجة النهائية:
- **Landing Page**: `https://YOUR_USERNAME.github.io/instagrab/`
- **Download Link**: `https://YOUR_USERNAME.github.io/instagrab/Instagrab.exe`
